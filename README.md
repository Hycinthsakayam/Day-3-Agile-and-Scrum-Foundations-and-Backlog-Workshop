# Day 3 – Agile and Scrum – Foundations and Backlog Workshop

This repository contains my answers for the Day 3 assignment on Agile and Scrum. Each question is in its own folder with my written answer and any supporting files.

The assignment has three sets, with six questions in each set.

## What I'm working on

- Writing a product vision and mapping people to Scrum roles.
- Breaking epics into user stories in the 'As a / I want / so that' format.
- Reviewing stories against INVEST and splitting large ones vertically.
- Writing Given / When / Then acceptance criteria.
- Prioritising (MoSCoW, value vs effort) and estimating with Planning Poker.
- Preparing the JIRA board, Definition of Ready and Definition of Done.
